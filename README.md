# MOSA OSINT — Android Native

Kotlin + Jetpack Compose prototype for privacy-respecting analysis of public information.

## Initial scope
- Native Android application
- Local phone-number format validation only
- Planned modules for public-profile research, business verification, and privacy auditing
- No WhatsApp private-data access, scraping, or privacy bypass

## Build
GitHub Actions workflow builds a debug APK on pushes to `main` and manual dispatch. Download the `MOSA-OSINT-debug-apk` artifact from the Actions run.
